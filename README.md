# Drama Workshop · AI 剧组生产流水线

> 我们交付的不是「视频生成器」，而是一条 **AI 剧组流水线**——把专业微短剧剧组的分工方式与生产纪律产品化。普通用户不懂运镜、景别、轴线，也能像导演一样下决策，拿到专业级的成片制作包。

**用户旅程**：选题材 → 输入一句话梗概 → 全组开机 → AI 剧组自动完成剧本/定妆/拆镜/组装/后期 → 下载 9:16 竖屏成片与完整制作包 → 一键续写下一集（角色定妆跨集沿用）。

## 产品叙事：剧组六步（§1.4 口径）

| # | 流水线阶段 | 剧组角色 | 谁来做 |
| --- | --- | --- | --- |
| 0 | 制片立项 | 制片主任 | **用户**：选题材、给梗概、定参数、点开机 |
| 1 | 剧本创作 | 编剧 | AI：场次化推演（首场钩子 / 末场悬念） |
| 2 | 选角定妆 | 选角定妆 | AI + 用户过目：资产提取、定妆图、外观微调 |
| 3 | 导演拆镜 | 导演 | AI + 用户修正：场次级拆镜（景别/运镜/能量值/音效标注） |
| 4 | 锚定组装 | 场记 | AI 自动：确定性提示词组装 + 一致性锚点指纹 |
| 5 | 后期成包 | 后期 | AI + 用户验收：三轨落轨、转场/调色/字幕/配音混音、制作包 |

> **口径声明**：第 0 步是用户动作，不属于 ProductionRun 编排；代码与 UI 的阶段真相源是 `RUN_STAGES`（`src/lib/drama.ts`）= 开机后 AI 自动执行的五阶段。禁止把「制片立项」写进 RUN_STAGES 或任何阶段进度 UI。

**不是黑箱**：每一阶段的产出（剧本/定妆图/分镜）都在工作台留档，可改后继续；改动角色或场景设定会自动标出受影响的镜头（锚点过期机制），只补拍该补的；中途失败从断点续跑，已完成阶段不重来。

## 快速开始

```bash
# 0) 依赖
bun install            # 或 npm install

# 1) 数据库（SQLite，开箱即用；连接串见 .env.example）
cp .env.example .env
bun run db:push        # prisma db push（首建表结构）

# 2) 启动
bun run dev            # http://localhost:3000

# 3)（可选）零配额演示数据：3 幕 / 10 镜 / 5 资产 / 成片可播放
node scripts/seed-demo-project.mjs
```

**通道缺省策略（重要）**：视频通道缺省为 `noop` 占位——批量流水线/一键渲染**零视频配额消耗**，任务秒级落 failed 并透出引导文案。真实通道显式 opt-in：`VIDEO_PROVIDER=zai`（配额窗口确认后再开，见 `docs/architecture-v2.md` §7.4）。

## 技术栈与结构

Next.js（App Router）+ TypeScript + Tailwind + Prisma（SQLite）+ 本地 ffmpeg 合成。

```
src/
  app/                  # 落地页 + 工作台（单页会话态）+ API 路由
  components/workbench/ # 工作台面板（剧组进程/剧本/资产库/分镜/节奏/成片）
  server/services/      # 领域服务（screenplay/breakdown/compose/series/task…）
  lib/drama.ts          # 领域类型与常量真相源（RUN_STAGES / CAMERA_MOVEMENTS…）
  config/               # 运行参数与模板（零硬编码：业务代码禁 process.env/魔法数字）
scripts/
  assemble-episode.py   # ffmpeg 成片合成（片头卡/转场矩阵/调色/字幕烧录/配音混音/响度归一）
  seed-demo-project.mjs # 零配额演示数据
  ui-verify-series.cjs  # 连载动线 UI 回归（动态断言 + 自清理）
  vlm-audit-product.mjs # VLM 产品总监视角走查（仅图片理解，零生成配额）
docs/
  architecture-v2.md    # 架构与实施记录真相源（版本历史/设计决策/验收记录都在这）
```

## 核心设计（详见 docs/architecture-v2.md）

- **一致性锚定（C1/C2）**：角色/场景/道具资产带锚点描述串与指纹；改动锚点 → 引用镜头标「锚点过期」→ 重新组装恢复一致性；视频通道提交时自动携带主要角色定妆图作首帧参考（§7.1.4，通道拒绝时优雅降级）。
- **提示词组装管线（C3）**：`composeVideoPrompt` 确定性组装（角色 → 场景 → 道具 → 动作 → 运镜 → 影调 → 技术段）；中文景别/运镜映射为英文电影术语；前端微调只允许改段重组，不破坏锚点。
- **异步任务管线（C4/C5）**：内存队列 + 并发上限 + 429 指数退避 + 断点重试 + 重启恢复。
- **连载生产线（C10）**：独立项目自动 adopt 为系列第 1 集；续写继承题材/参数并克隆资产库（同一角色跨集同一张脸）；系列级批量补拍。
- **制作包交付**：零依赖 ZIP（成片/镜头素材/定妆图/配音/分镜表/字幕 SRT/工程档案）。

## 工程纪律

- 零硬编码：业务代码禁止 `process.env`、魔法数字与内嵌文案（§7.8）。
- 色彩纪律：语义色全局收口，紫色系禁用（§7.13）。
- 验收文化：每个版本独立可验收，`docs/architecture-v2.md` §10 留有实施记录与验收证据。
- 术语零容忍：全站不得残留「3 幕节拍/三幕结构」表述（历史整改令）。
